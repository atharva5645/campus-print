# CampusPrint

CampusPrint is a React + Vite frontend with an Express backend and Supabase integration for campus printing workflows.

## Tech Stack
- React + Vite
- Express
- Supabase
- Tailwind CSS

## Local Setup

### Frontend
```bash
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```

### Run Both
```bash
npm run dev:all
```

## Environment Files
Create local env files from the examples:
- `.env.example`
- `backend/.env.example`
